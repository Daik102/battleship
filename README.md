<h1>Project: Battleship</h1>
A battleship app with several features.
<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Object-Oriented Game Design

- Displaying player ranks after the battle

- Storing hi-scores using localStorage

- Keyboard support

- Responsive Design implemented

<h3>Tech Stack</h3>

- Frontend: HTML CSS JavaScript

- Build Tool: Webpack

- Icons: <a href="https://pictogrammers.com/">Pictogrammers</a>
